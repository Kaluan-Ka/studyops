# Observabilidade para estudos

## Objetivo

Registrar o próprio fluxo de aprendizagem como dados úteis: item estudado,
status, tags, anotações, tempo gasto, evidências e próxima aplicação.

## MVP

Cadastrar item de estudo, link, status, tags e anotações; usar os estados ler,
estudando, feito e ignorado; listar por tema e registrar resumo manual.

## Evoluções

Adicionar dashboard semanal, linha do tempo de projetos, resumo assistido,
recomendação do próximo estudo e exportação para Markdown.
